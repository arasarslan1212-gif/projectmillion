# Decisions

Where the spec was ambiguous, or reality forced a choice, the option most honest to the end user wins. Each entry records the choice, the reason, and what it affects.

---

### D-001: Synthetic fixtures while the network is blocked
**Context.** Egress to every data provider is blocked in the build environment, so the 6 real tickers can't be recorded.
**Decision.** Ship two fixture sets that go through the same record/replay HTTP layer and the same adapters:
- `fixtures/recorded/`: real responses, produced by `make record-fixtures` (AAPL, JPM, O, an unprofitable growth name, a high-dividend utility, a sparse small cap).
- `fixtures/synthetic/`: generated by `scripts/make_synthetic_fixtures.py` for fake tickers `ZZTEC, ZZBNK, ZZREI, ZZGRO, ZZUTL, ZZSML` plus a synthetic peer universe.

Synthetic companies are named "… (Synthetic)". Every page that shows them carries a persistent **SYNTHETIC TEST DATA: NOT A REAL COMPANY** banner, and charts carry a watermark. The flag is `companies.is_synthetic`, set from fixture metadata and never inferred.
**Why.** "Never invent data" is about misleading users. Clearly labeled synthetic fixtures with non-existent tickers can't be mistaken for real data, and they let every code path be tested now.

### D-002: The 12-month target is not intrinsic value
The engine estimates intrinsic value V with each method. The **long-term intrinsic value** is V. The **12-month P50** is `P0 · (1 + k_e − dividend_yield) · exp(λ · ln(V/P0))`, with λ = `valuation.convergence_12m` (default 0.4).
**Why.** Assuming full convergence in 12 months is not supported by evidence and produces over-confident targets. λ is visible on the Methodology page, and the backtest measures whether it's miscalibrated.

### D-003: The price range is an honest 80% interval
P10/P90 come from a log-normal with σ² = σ_mkt² + (λ·σ_val)², multiplied by a widening factor `1 + w·(1 − confidence/100)`. σ_mkt is the 1-year realized volatility (implied volatility when available). σ_val is the log-dispersion of the Monte Carlo intrinsic values combined with the dispersion between methods.

### D-004: Charts use ECharts, not Recharts
Radar, heatmap, tornado, histogram with reference lines and bubble scatter are all first-class in ECharts. Recharts has no heatmap. Price charts use TradingView Lightweight Charts, with the attribution logo on and a NOTICE credit on the About page.

### D-005: Without an LLM key, templates are used and sentiment is not estimated
With no `ANTHROPIC_API_KEY`, every narrative uses deterministic templates built from the facts JSON; these always pass the validator. News sentiment is **not** estimated with a crude word list. It is shown as "not computed (LLM not configured)", and the Sentiment pillar is reweighted away, with the missing input listed.

### D-006: Analyst data tiers and labels
`pro` = Benzinga via Massive (per-analyst). `starter` = FMP `price-target-news` (per-analyst targets) joined to FMP grades for ratings (same firm, ±3 days). `free` = Finnhub recommendation trends (consensus distribution only). The UI states which level applies: "Per-analyst track records", "Firm-level track records only", or "Consensus only".

### D-007: Benchmarks
The S&P 500 is proxied by **SPY** (adjusted close, so total return). Sectors use the SPDR Select Sector ETFs (XLK, XLF, XLE, XLV, XLI, XLY, XLP, XLU, XLRE, XLB, XLC). The proxy is labeled wherever it's used.

### D-008: Stock-based compensation
SBC is treated as a real expense. GAAP operating income already deducts it, so FCFF built from NOPAT never adds SBC back. "FCF" shown in quality metrics is CFO − capex, alongside "FCF after SBC" (CFO − capex − SBC).

### D-009: Stale analyst targets
Targets older than `analysts.stale_months` (default 6) are greyed out and excluded from both consensus figures. This matches the spec's default.

### D-010: Meaning of the Trust Rating
The Trust Rating measures business strength, reliability and valuation *relative to sector*. It is **not** a buy/sell recommendation and is never phrased as one. Grade bands: A+ ≥ 90, A ≥ 85, A− ≥ 80, B+ ≥ 75, B ≥ 70, B− ≥ 65, C+ ≥ 60, C ≥ 55, C− ≥ 50, D ≥ 40, F < 40.

### D-011: Docker isn't testable in the build environment
Compose files are provided, but the Docker daemon isn't available here. Local verification uses SQLite and a local PostgreSQL 16 instance for migrations.

### D-012: PDF export
PDF export uses a dedicated print stylesheet plus the browser's print-to-PDF. This needs no server dependency, and what you see is what you get. Server-side rendering with Playwright is on the ROADMAP.

### D-013: The synthetic set is generated in-process, and fixture sets never mix
The synthetic "fixtures" are served by an in-process HTTP transport (`engine/synthetic/server.py`), not stored as files. It speaks each provider's documented response shape, so the real adapters parse it exactly as they would parse live data. It is deterministic (seeded), which keeps the repository small and stops synthetic fixtures from going stale. Mock mode uses exactly one set (`FIXTURE_SET`: `recorded` | `synthetic` | `auto`). Synthetic companies can therefore never be ranked against real ones, and real benchmark tickers (SPY, XLK, …) are never given synthetic prices: the synthetic set uses its own benchmarks (`ZZMKT`, `ZZSTK`, …).

### D-014: Chart palette
Charts use the validated reference palette from the data-viz method (fixed categorical order, reserved status colors, one-hue sequential, blue↔red diverging with a gray midpoint), defined once as CSS tokens in `apps/web/app/globals.css` for light and dark themes. Muted text is darkened to `#6b6a65`, so small text meets WCAG AA (4.5:1) on the light surface.

### D-015: Name
Working name "Candor" (fits the honesty-first product). Rename it in `apps/web/lib/legal.ts`.

### D-016: Every indicator is computed in the engine
SMA/EMA/Bollinger/RSI/MACD are computed in Python and sent with the chart data, so the browser only draws. The price chart's "% compare" mode uses the chart library's percentage scale, which rebases each displayed series to its first visible value. That is display scaling, not a new figure.
